Önizleme:

2. “Sürprizi aç” düğmesine bas.
3. Tarih: 21 Ocak 2026
4. Şifre: Yavrum

İNTERNETTE YAYIMLAMA (ücretsiz seçenek: Netlify Drop)
1. ZIP dosyasını aç ve içindeki index.html dosyasını bir klasöre çıkar.
2. Netlify hesabı aç veya giriş yap: https://app.netlify.com/drop
3. index.html dosyasının bulunduğu klasörü sürükleyip bırak. (Arayüz klasörü kabul etmezse dosyayı tek başına değil, index.html içeren klasörü ZIP yapıp yükleme seçeneğini kullan.)
4. Netlify bir web adresi oluşturduğunda o adresi kopyalayıp sevgiline gönder.

Alternatif: GitHub Pages gibi statik site barındırma servisleri de kullanılabilir.
